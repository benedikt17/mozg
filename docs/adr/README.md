# Architecture Decision Records

В этом каталоге хранятся ADR для решений, изменяющих или уточняющих
`ARCHITECTURE.md`.

Рекомендуемый формат имени:

```text
0001-short-decision-title.md
```

Минимальная структура ADR:

```md
# ADR-0001: Название решения

- Status: proposed | accepted | superseded | rejected
- Date: YYYY-MM-DD

## Context

## Decision

## Alternatives considered

## Consequences

## Migration plan
```

Изменения неприкосновенных решений из §18 `ARCHITECTURE.md` запрещены
без принятого ADR.
