# Нейрокомментарии к статьям

Подключение ChatGPT к MCP МОЗГА может запросить два права:
`knowledge:read` и `knowledge:neurocomment:create`. Чтобы пользоваться
нейрокомментариями, обновите инструменты приложения в ChatGPT и вызовите
`list_knowledge_comments` или `create_knowledge_neurocomment`. Существующее
подключение только для чтения получит запрос на дополнительные права; на
странице МОЗГА подтвердите «Разрешить чтение и нейрокомментарии». Повторное
подключение через обычную кнопку «Подключить учётную запись» может запросить
только чтение, если ChatGPT ещё не обнаружил новые инструменты.

После подключения попросите ассистента прочитать статью инструментом
`read_knowledge_document`, а ваши заметки — `list_knowledge_comments`.
Затем он может вызвать `create_knowledge_neurocomment` с ID статьи, точной
уникальной цитатой из Markdown, текстом комментария и необязательным
`suggestedText` для замены цитаты. Право писать нейрокомментарии доступно
только владельцу рабочего пространства.

В режиме чтения статьи откройте «Комментарии» → «Нейро». Предложение с
заменой показывает «Было» и «Станет». Кнопка «Принять» меняет статью
только после вашего нажатия. Цитата должна остаться уникальной и неизменной.
Принятые соседние предложения учитываются при проверке исходного контекста;
они не блокируют остальные предложения того же документа. Необъяснённое
изменение контекста вручную остаётся конфликтом и требует повторной проверки.

Нажатие на цитату выделяет и открывает её место в статье; для принятой правки
показывается внедрённый текст. Привязка использует координаты исходного Markdown,
поэтому форматирование и переходы между абзацами не мешают навигации.
Свёрнутые ветви списков раскрываются для перехода. Для текстовых узлов с
декодированными escape/entity-последовательностями выделяется весь этот узел.

Перед принятием завершается локальное сохранение. После принятия интерфейс
ожидает серверную версию с внедрённой правкой, сохраняя открытую статью.
Если загрузка не удалась, сообщение и кнопка обновления остаются видимыми;
старый текст не считается подтверждением успешного обновления.

MCP не использует OpenRouter или отдельный OpenAI API ключ. Встроенное поле
чата на сайте пока не вызывает модель. Миграцию и OAuth нужно отдельно
проверить и включить в нужном окружении.
